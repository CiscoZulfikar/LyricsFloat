v1.1.1 260907b
✨ What's New
  • Translation Loading Indicator: Real-time spinning/glowing icon and floating pill ("Translating lyrics..." → "✓ Translation ready").
🛠️ What's Been Modified
  • Smart Vocalization Suppression: Repetitive singing syllables (e.g. "ル・ル・ル...") with Romaji cleanly suppress redundant translation walls, and Western vocal repetitions are auto-collapsed.
  • Pure English Fast-Path: Robust vocabulary and foreign marker scanning eliminates false translation triggers on purely English tracks.
🐛 What's Been Fixed
  • English Song Translation & Pill Hang: Fixed purely English songs (e.g. "Like You Do") getting falsely translated and leaving the loading pill spinning.
  • Vocalization Clutter Bug: Fixed katakana chanting generating 21 repeats of "Lulu" across 3 lines of italics right under Romaji.
v1.1.0 260907
✨ What's New
  • Parenthetical Vocal Translation: Intelligently translates foreign main vocals while preserving backing vocals (e.g. "Nadie como tú (We cried together...)").
  • English Language Toggle: Added English flag and checklist toggle to translate between English and other languages.
  • v2 Cache Engine: Upgraded translation cache system with auto-refresh for pristine lyrics.
🛠️ What's Been Modified
  • Concurrent Translation Pipeline: Optimized per-line translation (~150ms) with zero rate-limit risk.
  • Accurate Language Detection: Each line is classified independently, preventing language overlap in bilingual tracks.
  • Smart English Bypass: Fast-paths purely English songs to save network bandwidth while keeping bilingual songs active.
  • Homoglyph Normalization: Integrated normalizeHomoglyphs to clean confusable letters from scraped lyrics.
🐛 What's Been Fixed
  • Multi-Translation Bug: Fixed foreign verses in bilingual songs failing to translate.
  • Homoglyph Duplicate Leak: Sanitized Cyrillic lookalikes (e.g. Therе's) so English lines no longer show duplicate text.
  • Indonesian/Malay Mutual Detection: Resolved false translations for Indonesian songs with Indonesian target.
  • Checklist Language Suppression: Fixed hanging promises when disabling languages.
